# 全局 Copilot Instructions（团队）

目的：为团队提供一套全局的 Copilot 指令，确保生成的代码和文档符合团队约定。

请在生成代码或文档时优先满足以下要求：

- 语言：默认中文用于团队文档，代码注释可用中文/英文混合；对外公开的 README 或开源内容优先使用英文。
- 风格：遵循仓库中已有命名与目录结构，优先保持现有代码风格。
- 注释：重要函数与模块必须带简要注释（2-3 行），公共 API 应有 JSDoc 注释。
- 测试：建议为新增逻辑添加单元测试，覆盖正常路径与至少一个边界错误路径。

当遇到与支付或用户隐私相关的实现时，请在注释中标注“模拟/示例实现”，不要包含真实凭证。
