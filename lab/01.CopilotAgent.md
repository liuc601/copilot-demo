# Lab 01 - CopilotAgent

概述

- 使用 VS Code 中的 CopilotAgent 生成 PRD 并初始化一个旅游站点项目的流程演示。

目标

- 生成简单的 PRD（产品需求文档）。
- 基于 PRD 初始化前端/后端项目骨架并提交到本地 Git。

前置条件

- 已安装 VS Code、Git。
- 已配置 GitHub Copilot 或相关扩展、Node.js（如需前端脚手架）。

步骤

1. 在 VS Code 中打开工作区。
2. 启动 CopilotAgent，输入“生成旅游站点 PRD”并确认产出。
3. 根据 PRD 使用脚手架（如 create-react-app / vite）初始化前端项目：
   - npm init vite@latest my-trip-site --template react
4. 添加基本 README、LICENSE 并初始化 Git 提交：
   - git init && git add . && git commit -m "init: project from PRD"
5. 记录 PRD 与实现差异，保存到 docs/PRD.md。

产出 / 检查点

- docs/PRD.md（生成的 PRD）
- 前端项目骨架（package.json、src/ 等）
- 初始提交记录

参考

- VS Code Copilot 文档
- create-react-app / Vite 官方文档
